# IPscope

A responsive IPv4 and IPv6 intelligence dashboard that displays approximate network location, ISP, organization, ASN, protocol, postal region, and timezone data.

## Project structure

- `index.html` — page structure and accessible interface
- `styles.css` — responsive layout, visual design, and animations
- `script.js` — IP validation, API requests, result rendering, and interactions
- `vercel.json` — Vercel hosting configuration

## Run locally

Serve this directory with any static HTTP server and open `index.html`.

## Data source

Geolocation data is provided by the IPWhois API. Results identify a network area, not an individual or precise physical address.
